# PolarRec 0.4.0 · 앱·브라우저 창 녹화

- 선택한 앱 창을 Windows.Graphics.Capture로 녹화합니다. Windows 10 1903 이상 또는 Windows 11이 필요합니다.
- 브라우저의 현재 창을 대상으로 하며 탭을 바꾸면 바뀐 탭이 녹화됩니다.
- 창 크기 변경 시 최초 영상 크기에 비율을 유지해 맞춥니다.
- 최소화·닫힘을 감지하면 일시정지 처리를 시도하며 전체 화면으로 전환하지 않습니다.
- 창 모드에서는 PC 전체 소리를 기본으로 끕니다. 켜면 다른 앱의 소리도 녹음됩니다. 앱별 소리 분리는 지원하지 않습니다.
- 보호된 콘텐츠·일부 앱의 캡처는 제한될 수 있습니다.

설치 파일: PolarRec-0.4.0-Setup.exe (FFmpeg와 .NET 포함)

[설치·사용 가이드](https://github.com/Polar-Little-Lab/polarRec/blob/main/docs/USER-GUIDE.md)

사전 공개 버전입니다. 일반 Windows PC에서 오디오 동기화·장시간 녹화·다양한 앱 조합 검증은 추가로 필요합니다.

검증: Windows 빌드·창 핸들 지정 회귀 검사 통과. GitHub 실행 환경의 D3D11 장치 부재로 실제 창 격리 시험은 생략됐습니다. 캡처 성공으로 간주하지 않습니다.
