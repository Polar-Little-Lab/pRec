# PolarRec 0.4.3 · 창과 모니터 선택 UI 개선

- 앱 디자인에 맞춘 흰색·파란색 선택 상자와 목록을 적용했습니다.
- 앱 이름과 창 제목을 두 줄로 구분하고 긴 제목은 말줄임 및 툴팁으로 확인합니다.
- 선택 전 안내, 선택 항목 체크 표시, 키보드 포커스를 추가했습니다.
- 모니터 선택 UI를 통일하고 창 목록 버튼을 ‘갱신’으로 표시했습니다.

FFmpeg와 .NET 포함. 기존 앱을 종료한 뒤 새 설치 파일을 실행하세요.
사전 공개 버전입니다. 실제 창 녹화는 그래픽 장치가 있는 PC에서 추가 검증이 필요합니다.
