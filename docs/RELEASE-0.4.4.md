# PolarRec 0.4.4 · 오버레이 선택 방지

- 보고된 NVIDIA Share / NVIDIA GeForce Overlay 조합을 녹화 목록에서 제외합니다.
- 비활성 보조 창과 도구 창을 확장 스타일로 필터링합니다. 일반 앱으로 명시된 도구 창은 유지합니다.
- NVIDIA 앱 전체나 ‘Overlay’ 단어가 들어간 브라우저 제목을 일괄 차단하지 않습니다.
- 목록 표시뿐 아니라 미리보기·녹화 시작·재개 시에도 현재 창 속성을 재검사합니다.
- 선택한 창이 숨겨진 상태로 바뀌면 녹화를 계속하지 않도록 확인합니다.

모든 앱의 캡처 성공을 보장하는 필터는 아닙니다. 보호된 콘텐츠 등은 별도로 캡처에 실패할 수 있습니다.
FFmpeg·.NET 포함. 기존 앱을 종료한 뒤 설치하세요. 실제 창 녹화는 그래픽 장치가 있는 PC에서 추가 검증이 필요합니다.
