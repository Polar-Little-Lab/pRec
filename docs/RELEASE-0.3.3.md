# PolarRec · 폴라렉 0.3.3

Windows 10·11 x64용 화면 녹화 앱의 사전 공개 버전입니다.

- 전체 화면·선택 영역 녹화, PC 소리·마이크, 일시정지, MP4 저장
- Ctrl + Shift + F9: 녹화 시작 / 저장
- Ctrl + Shift + F10: 일시정지 / 계속
- B 포커스 북극곰 아이콘과 Frost 디자인
- 이전 Polar Recorder 설정·영상 폴더 호환
- FFmpeg와 .NET 포함: 별도 다운로드나 경로 설정 불필요

`PolarRec-0.3.3-Setup.exe`를 다운로드하세요. `Source code` ZIP은 개발자용 소스입니다.

[설치 및 사용 가이드](https://github.com/Polar-Little-Lab/polarRec/blob/main/docs/USER-GUIDE.md)

Windows 실제 설치·녹화·오디오 동기화 테스트는 아직 완료하지 않았습니다. 중요한 녹화 전 짧은 시험 녹화를 권장합니다. 코드 서명과 자동 업데이트는 제공하지 않습니다.
