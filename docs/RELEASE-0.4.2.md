# PolarRec 0.4.2 · 시스템 창 오류와 녹화 화면 배치 개선

- Program Manager, 바탕화면 WorkerW, 작업 표시줄을 창 선택 목록에서 제외합니다.
- explorer.exe 전체를 차단하지 않으므로 일반 파일 탐색기 창은 유지합니다.
- 시작·미리보기 시에도 시스템 창을 재검사합니다. 바탕화면은 전체 화면 또는 선택 영역 모드를 사용하세요.
- 창 캡처 실패 시 긴 Stream mapping 출력 대신 한국어 안내를 표시합니다. 미리보기 실패 로그는 로컬 진단 폴더에 보관합니다.
- 창 캡처 실패 시 다른 화면으로 자동 전환하지 않습니다.

FFmpeg와 .NET 포함. 기존 앱을 종료한 뒤 PolarRec-0.4.2-Setup.exe를 설치하세요.
사전 공개 버전이며 일반 Windows PC의 실제 녹화 검증은 추가로 필요합니다. 자동 환경의 그래픽 장치 부재로 실제 캡처 시험이 생략될 수 있으며 통과로 간주하지 않습니다.

- 좌우 카드 행 높이를 맞춰 하단 경계를 정렬했습니다.
- 창 목록 새로고침을 선택 상자 옆에 배치하고 미리보기 갱신과 구분했습니다.
- 소리와 포인터를 같은 카드에 정리하고 중복 안내를 줄였습니다.
- 작은 창 및 높은 배율에서는 스크롤을 유지합니다. 실제 Windows 화면 배치 검증은 추가로 필요합니다.
