# PolarRec 0.4.5 · 모드별 소리 설정과 상단 알림

- 앱·브라우저 창 모드에 들어갈 때만 PC 소리를 기본으로 끕니다.
- 전체 화면·영역 모드로 돌아오면 이전 화면 녹화의 PC 소리 설정을 복원합니다. 직접 꺼둔 설정은 유지합니다.
- 창 모드의 임시 소리 설정이 화면 녹화의 저장 설정을 덮어쓰지 않습니다. 마이크 설정은 별도로 유지됩니다.
- 이전 버전은 자동 꺼짐과 직접 꺼짐을 구분해 저장하지 않았으므로 첫 업데이트 시 화면 녹화 PC 소리를 켜짐으로 초기화합니다. 이후 직접 변경한 설정은 저장됩니다.
- 안내가 상단에서 내려와 4초 뒤 사라집니다. 오류는 12초 표시하며, 마우스 또는 키보드 포커스가 알림 안에 있으면 유지합니다.
- 최근 안내 버튼으로 마지막 메시지를 다시 확인할 수 있습니다. 알림이 녹화 설정 영역의 높이를 줄이지 않습니다.

FFmpeg·.NET 포함. 기존 앱을 종료한 뒤 설치하세요. 실제 창 녹화는 그래픽 장치가 있는 PC에서 추가 검증이 필요합니다.
