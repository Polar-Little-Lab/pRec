# pRec · Polar UI Frost 기준 적용

공통 기준: https://github.com/Polar-Little-Lab/design-system — 0.1.0의 tokens/frost.json.
적용 앱: pRec 0.4.7. 색상·간격·타이포그래피 등 시각 기준만 공유하며 WPF 화면 구성과 동작은 제품에서 관리합니다.

## 시각 기준
- 배경 #F3F8FC, 표면 #FFFFFF, 보조 표면 #E7EFF6.
- 본문 #213347, 보조 글자 #586D80, 경계 #C8D8E5.
- 주요 실행·포커스 #32678C, 오류·녹화 상태 #B44848, 주의 #94601F, 성공 #287761.
- 레이아웃 간격 4·8·12·16·24·32 DIP. 패널 안쪽 16, 화면 바깥 24, 열 사이 16.
- 기본 버튼 최소 높이 40, 버튼 모서리 8, 선택 팝업 모서리 10, 포커스 두께 2 DIP.
- 본문 13, 설명 11–12, 페이지 제목 24 DIP. Windows 기본 서체를 사용합니다.

WPF 리소스는 src/PolarRecorder/Themes/Frost.xaml에서 관리합니다. 공통 저장소의 React/Qt 컴포넌트를 직접 사용하거나 자동 동기화하는 방식은 아닙니다.

## 제품별 유지 사항
- 카드 모서리 12, 2열 녹화 준비 화면과 고정된 하단 녹화 조작을 유지합니다.
- 앱·창 이름 두 줄을 표시하는 선택 메뉴의 최소 높이 52를 유지합니다.
- 갱신·폴더 변경 등 보조 버튼의 작은 크기와 오디오 토글을 유지합니다.
- 제품 아이콘, 타이머 글꼴·크기, 미리보기 도형은 별도 제품 자산입니다.
- 알림은 화면 상단에서 최대 3초 표시합니다. 마우스·키보드 포커스로 연장하지 않으며 최근 안내에서 마지막 메시지를 다시 확인합니다. 이 동작은 사용자가 지정한 제품 정책입니다.
- 전체 화면/영역의 PC 소리 설정 보존, 창 진입 시 기본 음소거, 마이크·단축키·녹화 기능은 변경하지 않습니다.

## 검증
Windows CI에서 WPF 빌드, 기본/최소 화면의 카드 정렬·스크롤, 알림의 레이아웃 영향과 오디오 모드 전환 회귀 검사를 수행합니다. 실제 Windows 녹화·스크린 리더·다중 DPI 검증과는 구분합니다.
