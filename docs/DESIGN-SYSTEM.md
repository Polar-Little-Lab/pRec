# Polar Recorder · Frost 0.2

## 방향

Polar Apps의 흰색·아이스 블루 계열을 WPF 데스크톱 도구에 적용한다.
큰 홍보 문구, 장식 카드, 초록색 포인트를 사용하지 않는다. 기본 Windows 창 프레임을 유지한다.
주요 작업은 녹화 준비 → 녹화 → 저장이며, 다른 화면에서도 녹화 상태와 조작을 찾을 수 있어야 한다.

참조: Polar Apps `https://polar-apps-lab.namsh11251.chatgpt.site/style.css` (2026-10-25 확인).
사이트의 배경 #F0F5FA, 본문 #22303B, 경계 #D6DDE3, 아이스 블루 #ABCFED를 공유한다.
기존 PolarSH/Frost 선호사항을 참고했으며 PolarSH 네이티브 스타일 파일 전체를 대조한 것은 아니다.

## 색상

| 역할 | 토큰 | 값 | 사용 |
|---|---|---|---|
| 바탕 | CanvasBrush | #F0F5FA | 창 배경, 미리보기 바탕 |
| 표면 | SurfaceBrush | #FFFFFF | 헤더, 설정 패널, 녹화 바 |
| 본문 | InkBrush | #22303B | 제목, 레이블 |
| 보조 | MutedBrush | #536D82 | 안내문, 부가 정보 |
| 경계 | LineBrush | #D6DDE3 | 구분선, 입력 테두리 |
| 선택 배경 | IceBrush | #E7F2FC | 선택 탭, 화면 모드, 첫 설정 안내 |
| 아이스 블루 | AccentBrush | #ABCFED | 브랜드 보조색, 영역 선택 테두리 |
| 주요 행동 | ActionBrush | #245D85 | 녹화 버튼, 토글 켜짐, 키보드 포커스 |
| 오류 | ErrorBrush | #A53939 | 오류 상태 |
| 녹화 | — | #B84242 | 녹화 중 상태 점 |
| 일시정지 | — | #956013 | 일시정지 상태 점 |

밝은 #ABCFED 위에 흰 본문을 두지 않는다. 본문과 주요 버튼은 충분한 명도 대비를 가진 짙은 색을 사용한다.
상태는 색과 텍스트를 함께 표시한다. 빨강/황색은 상태에만 사용하고 브랜드 포인트로 확장하지 않는다.

## 글꼴과 간격

- Windows 기본 서체: Segoe UI / Malgun Gothic. 폰트 다운로드 없이 실행한다.
- 앱 이름 21, 화면 제목 22, 구역 제목 15, 본문 13, 안내 12, 보조 메타데이터 11 DIP.
- 숫자 타이머: Consolas 22 DIP. 24시간 이후에도 총 시간을 표시한다.
- 창 기본 1000 × 810 DIP, 최소 880 × 730 DIP. 작은 높이에서는 내용 영역만 스크롤한다.
- 바깥 간격 24, 패널 안쪽 20, 열 사이 20, 패널 사이 12, 관련 요소 사이 6~10 DIP.
- 패널 모서리 12, 컨트롤 모서리 7~8, 기본 버튼 높이 최소 38 DIP.
- 그림자·그라디언트·유리 효과를 기본 구성 요소에 넣지 않는다.

## 공통 구성 요소

`src/PolarRecorder/Themes/Frost.xaml`을 공통 스타일의 원본으로 사용한다.

| 구성 요소 | 동작 |
|---|---|
| PrimaryButton | 현재 작업의 핵심 행동 하나를 강조한다. 준비 상태에서는 시작, 녹화 중에는 저장. |
| NavButton | 녹화 / 내 녹화 / 설정. 선택 탭은 아이스 블루 배경. |
| CaptureChoice | 전체 화면 / 선택 영역. 선택 상태에 테두리와 점을 함께 사용. |
| CheckBox 토글 | PC 소리, 마이크, 포인터. 켜짐/꺼짐은 위치와 색으로 구분. |
| FocusRing | 키보드 이동 시 짙은 파란색 외곽선 표시. |
| Panel | 흰색 배경, 얇은 테두리, 일정한 패딩. |
| NoticePanel | 오류·복구 안내. 여러 줄/긴 경로는 높이를 제한하고 스크롤. |

## 사용자 흐름과 상태

- 초기 설정: FFmpeg를 찾지 못하면 시작 버튼을 비활성화하고 ‘설정 열기’를 제공한다.
- 녹화 준비: 모니터 → 전체/영역 → PC 소리/마이크. 선택 내용을 오른쪽 요약에서 확인한다.
- 화면 미리보기: 사용자가 ‘새로고침’을 눌렀을 때만 화면을 한 번 캡처한다. 디스크에 저장하거나 전송하지 않는다. 실시간 영상이 아니다.
- 선택 영역: 물리 픽셀 크기를 표시하고 Esc 취소를 제공한다. 모니터 또는 모드 변경 시 이전 미리보기를 지운다.
- 카운트다운: 3초 대기 중 ‘시작 취소’와 Esc를 제공한다. 취소 시 녹화 세션 파일을 만들지 않는다.
- 녹화 중: 설정을 잠그고 하단 바에 경과 시간, 일시정지, 저장을 표시한다. 시작 시 창은 최소화된다.
- 일시정지: ‘계속 녹화’로 버튼 문구를 바꾸고 멈춘 시간이 제외됨을 안내한다.
- 저장 중: 중복 조작을 막고 저장 상태를 표시한다.
- 저장 완료: 파일명과 ‘영상 열기’를 표시한다.
- 내 녹화: 현재 저장 폴더의 최신 MP4 50개. 더블 클릭, Enter, 열기 버튼으로 기본 재생기 실행. 삭제 기능은 없다.
- 오류: 하단에 읽을 수 있는 안내를 표시한다. 녹화 중 닫기는 저장 확인이 필요하다.

## 접근성 및 검증 범위

기본 창 프레임·키보드 포커스·컨트롤 의미를 유지하며 주요 컨트롤에 접근성 이름을 넣었다.
준비/녹화/일시정지/오류에 색상만 사용하지 않는다. 작은 창에서는 작업 바가 스크롤되지 않는다.

Windows 실기기에서 스크린 리더, 키보드 탐색, 125/150/200% DPI, 화면 캡처, 음성 동기화를 추가 확인해야 한다.
`Frost-preview.png`는 코드 구조와 공통 색상에 맞춘 디자인 시안이며 Windows 실행 화면 캡처가 아니다.

## 0.3 배포 흐름 변경

녹화 엔진을 앱에 포함한다. FFmpeg 경로 입력·파일 선택·PATH 탐색을 제거한다. 초기 설정 없이 시작하며, 구성 파일 누락 시에만 ZIP 전체 재압축 해제 안내를 보여 준다. 기존 문서의 엔진 연결 흐름은 0.2 기록이다.
