# PolarRec · 폴라렉 설치 및 사용 가이드

<section><h2 id="before">시작 전에</h2><p>PolarRec · 폴라렉은 화면과 PC 전체 소리·마이크를 함께 담는 Windows 녹화 앱입니다. 이 안내서는 <strong>0.4.0</strong> 기준입니다.</p><ul><li>대상: Windows 10·11, x64 PC. macOS·Linux용 앱은 제공하지 않습니다.</li><li>설치 파일: <code>PolarRec-0.4.0-Setup.exe</code>. FFmpeg와 .NET 런타임이 들어 있어 따로 찾거나 설치할 필요가 없습니다.</li><li>기본 저장 형식은 MP4, 프레임 속도는 30 FPS입니다.</li></ul><blockquote>설치 스크립트와 앱 소스를 대조해 작성했습니다. 개인 Windows PC에서의 설치·녹화 검증과 실제 앱 화면 촬영은 아직 완료하지 않았습니다.</blockquote></section>
<section><h2 id="installation">1. 설치하기</h2><ol><li>기존 Polar Recorder 또는 PolarRec을 사용 중이면 녹화를 저장하고 앱을 종료합니다.</li><li><code>PolarRec-0.4.0-Setup.exe</code>를 실행합니다.</li><li>설치 시작 안내를 읽고 다음으로 진행합니다.</li><li>구성 요소에서 <strong>PolarRec (필수)</strong>를 유지합니다. 바탕화면 아이콘이 필요하면 <strong>바탕화면 바로가기</strong>를 선택합니다.</li><li>설치를 시작하고 완료될 때까지 기다립니다.</li><li>완료 화면에서 <strong>PolarRec 실행</strong>을 선택하거나 시작 메뉴의 PolarRec을 실행합니다.</li></ol><p>현재 사용자 계정에 설치됩니다. 신규 설치 위치는 <code>%LOCALAPPDATA%\Programs\PolarRec</code>입니다. 이전 설치가 등록되어 있으면 그 위치를 재사용합니다. 설치 위치를 고르는 단계는 없습니다.</p><p>현재 배포본에는 코드 서명이 없습니다. 보안 경고가 나오면 파일 이름과 배포 출처를 확인하세요. 회사 PC에서 정책으로 차단되면 담당자에게 문의하세요.</p></section>
<section><h2 id="first">2. 첫 녹화: 10초만 시험하기</h2><ol><li>상단 <strong>녹화</strong> 화면에서 <strong>전체 화면</strong>을 선택합니다.</li><li>모니터 목록에서 녹화할 모니터 하나를 고릅니다.</li><li>필요한 <strong>PC 전체 소리</strong>와 <strong>마이크</strong>를 켭니다.</li><li><strong>저장 위치 → 변경</strong>에서 영상이 저장될 폴더를 확인합니다.</li><li><strong>녹화 영역 확인 → 새로고침</strong>으로 화면을 미리 확인합니다.</li><li>하단 <strong>녹화 시작</strong>을 누릅니다. 3초 준비 후 창이 최소화됩니다.</li><li>약 10초 뒤 <strong>Ctrl + Shift + F9</strong>를 누릅니다. 또는 작업 표시줄에서 앱으로 돌아와 <strong>저장하고 종료</strong>를 누릅니다.</li><li><strong>저장 완료</strong>가 표시되면 <strong>영상 열기</strong>로 화면과 소리를 확인합니다.</li></ol><p>‘저장하고 종료’는 현재 녹화를 마치는 버튼입니다. MP4를 만드는 동안에는 앱을 강제로 닫지 마세요. 시작 대기 중에는 <strong>시작 취소</strong> 또는 Esc로 취소할 수 있습니다.</p></section>
<section><h2 id="region">3. 필요한 부분만 녹화하기</h2><ol><li><strong>선택 영역</strong>을 고르고 대상 모니터를 선택합니다.</li><li><strong>영역 지정하기</strong>를 누릅니다.</li><li>화면에서 녹화할 사각형을 드래그합니다. 취소하려면 Esc를 누릅니다.</li><li>앱으로 돌아오면 선택 영역 표시를 확인한 뒤 녹화를 시작합니다.</li></ol><p>모니터를 바꾸면 영역을 다시 지정해야 합니다. ‘전체 화면’도 여러 모니터를 합치는 방식이 아니라 선택한 모니터 하나를 녹화합니다.</p><p>새로고침은 버튼을 누른 시점의 화면 한 장을 보여줍니다. 실시간 미리보기가 아닙니다. 창 미리보기는 임시 이미지 처리 후 삭제하며 사용자 영상 폴더에는 저장하지 않습니다. 마우스 움직임까지 보여주려면 <strong>마우스 포인터 포함</strong>을 켜세요.</p></section>
<section><h2 id="window">앱·브라우저 창만 녹화하기</h2><ol><li>녹화할 앱이나 웹페이지를 별도 창으로 열고 최소화를 해제합니다.</li><li>폴라렉에서 <strong>앱 · 브라우저 창</strong>을 선택합니다.</li><li><strong>창 목록 새로고침</strong>을 누르고 앱 이름과 창 제목을 확인해 대상을 고릅니다.</li><li>미리보기 새로고침으로 대상을 확인하고 녹화를 시작합니다.</li></ol><p>Windows 10 1903 이상 또는 Windows 11이 필요합니다. 화면 좌표 대신 선택한 창에 연결됩니다. 창 크기가 바뀌면 최초 녹화 크기에 비율을 유지해 맞추며 여백은 검정으로 채웁니다. 다른 창이나 전체 화면으로 자동 전환하지 않습니다.</p><p>브라우저에서는 주소 표시줄 등 창 내용과 현재 탭이 함께 녹화됩니다. 같은 창에서 탭을 바꾸면 바뀐 탭이 녹화됩니다. 특정 웹 탭 고정 기능은 아닙니다.</p><p>창이 최소화되거나 닫히면 일시정지 처리를 시도합니다. 창을 복원한 뒤 계속 녹화하거나 저장하세요. 닫은 앱을 다시 실행한 경우에는 기존 영상을 저장하고 새 창을 선택해 새 녹화를 시작하세요. 보호된 영상이나 일부 앱은 검은 화면이 나오거나 캡처가 차단될 수 있습니다.</p><p><strong>소리 범위:</strong> 창 모드 진입 시 PC 전체 소리는 기본으로 꺼집니다. 다시 켜면 다른 앱의 소리도 포함됩니다. 특정 앱만의 소리 분리는 지원하지 않습니다. 마이크는 별도로 선택할 수 있습니다.</p></section>
<section><h2 id="audio">4. PC 전체 소리와 마이크 선택하기</h2><table><thead><tr><th>녹화 목적</th><th>PC 전체 소리</th><th>마이크</th></tr></thead><tbody><tr><td>영상·음악 소리만</td><td>켜기</td><td>끄기</td></tr><tr><td>내 설명과 화면</td><td>필요에 따라</td><td>켜기</td></tr><tr><td>무음 화면 녹화</td><td>끄기</td><td>끄기</td></tr></tbody></table><p>앱은 Windows 기본 오디오 장치를 사용합니다. 앱 안에 장치를 고르는 메뉴는 없습니다. 원하는 스피커·헤드셋과 마이크를 Windows에서 기본 장치로 정한 뒤 녹화하세요. 녹화 도중 장치 교체는 피하고, 시험 녹화로 소리를 먼저 확인하세요.</p><p>스피커 소리가 마이크에도 들어가면 겹쳐 들릴 수 있습니다. PC 전체 소리와 마이크를 함께 녹음할 때는 헤드셋을 사용해 보세요.</p></section>
<section><h2 id="pause">5. 일시정지와 단축키</h2><table><thead><tr><th>동작</th><th>단축키</th></tr></thead><tbody><tr><td>녹화 시작 / 저장</td><td>Ctrl + Shift + F9</td></tr><tr><td>일시정지 / 계속 녹화</td><td>Ctrl + Shift + F10</td></tr><tr><td>영역 선택 / 시작 대기 취소</td><td>Esc</td></tr></tbody></table><p>녹화 중 <strong>일시정지</strong>를 누르면 잠시 멈추고, <strong>계속 녹화</strong>를 누르면 이어집니다. 마지막에 저장하면 이어 녹화한 구간이 하나의 MP4로 합쳐집니다.</p><p>연속 녹화 구간이 60분을 넘으면 자동으로 일시정지합니다. 안내를 확인하고 계속 녹화를 선택하세요. 단축키를 다른 앱이 사용 중이라는 안내가 나오면 폴라렉 창의 버튼을 이용하세요.</p></section>
<section><h2 id="files">6. 저장된 영상 찾기</h2><p>새로 사용하는 경우 기본 저장 폴더는 Windows의 <strong>동영상 폴더 안 PolarRec</strong>입니다. 기존 설정이나 <code>Polar Recorder</code> 영상 폴더가 있으면 이어서 사용합니다. 실제 위치는 앱의 <strong>저장 위치</strong>에서 확인하세요.</p><ul><li><strong>내 녹화:</strong> 현재 저장 폴더의 최근 MP4 50개를 표시합니다.</li><li><strong>열기:</strong> 선택한 영상을 기본 동영상 플레이어로 엽니다.</li><li><strong>저장 폴더 열기:</strong> 파일 탐색기로 폴더를 엽니다.</li><li><strong>설정 → 저장 폴더:</strong> 다음 녹화의 저장 위치를 바꿉니다. 이전 영상은 자동 이동하지 않습니다.</li></ul></section>
<section><h2 id="help">7. 문제가 생겼을 때</h2><h3>녹화 시작 버튼이 비활성화되어 있어요</h3><p>선택 영역을 아직 지정하지 않았는지, 구성 파일 누락 안내가 있는지 확인하세요. 녹화 또는 저장 작업 중에는 일부 설정이 잠깁니다.</p><h3>FFmpeg 파일이 없다고 나와요</h3><p>FFmpeg는 설치 프로그램에 포함되어 있습니다. 직접 경로를 찾을 필요가 없습니다. 앱을 종료하고 설치 프로그램을 다시 실행하세요. 구성 요소는 재설치 시 자동으로 복구됩니다.</p><h3>소리가 없어요</h3><p>PC 전체 소리·마이크 옵션과 Windows 기본 장치를 확인하세요. 마이크를 사용하는 경우 Windows의 데스크톱 앱 마이크 접근 설정도 확인한 뒤 짧게 재녹화해 보세요.</p><h3>저장이 실패했어요</h3><p>저장 위치의 여유 공간과 쓰기 권한을 확인하세요. 오류 안내에 복구용 파일 경로가 표시되면 그 폴더를 보존하세요. 저장 폴더의 <code>.polar-work</code> 아래 원본과 로그가 남을 수 있습니다. 복구가 끝나기 전에 삭제하지 마세요.</p><h3>영상이 목록에 없어요</h3><p>‘내 녹화’는 현재 저장 폴더만 봅니다. 저장 위치를 바꿨다면 예전 폴더를 파일 탐색기에서 열어 확인하세요.</p></section>
<section><h2 id="update">8. 업데이트와 제거</h2><p>업데이트 전 녹화를 저장하고 앱을 닫은 뒤 새 설치 프로그램을 실행하세요. 이전 설정은 새 이름의 설정 경로로 복사하고, 기존 영상은 옮기거나 삭제하지 않습니다. 자동 업데이트는 제공하지 않습니다.</p><p>제거하려면 시작 메뉴의 <strong>PolarRec → 제거</strong> 또는 Windows의 설치된 앱 목록에서 PolarRec을 선택하세요. 제거 프로그램은 앱 구성 파일을 삭제하며, 녹화 영상과 사용자 설정은 유지합니다.</p></section>
