# PolarRec 0.3.3 검증
- .NET 8 WPF win-x64 self-contained publish 성공.
- B-focus 아이콘을 그대로 사용.
- 신규 설치는 PolarRec 경로, 기존 설치는 등록된 InstallLocation 재사용.
- 기존 설정이 있으면 새 설정 경로로 복사하고 기존 원본은 유지.
- 기존 녹화 폴더가 있으면 유지. 사용자 영상은 이동하거나 삭제하지 않음.
- 제거는 패키지에 포함된 정확한 파일만 삭제.
- Linux 환경이므로 Windows 실제 설치, 녹화, 단축키 동작은 추가 확인 필요.
